# llm.txt - AI Context for The Claw Family Microsite

This file provides AI assistants with context about The Claw Family microsite project.

## Project Overview

The Claw Family microsite (https://ccagentorg.github.io/ai-agent-frameworks/) is a comprehensive guide to the open-source AI agent frameworks known collectively as "The Claw Family."

## The Claw Family Frameworks

### OpenClaw
- **GitHub:** https://github.com/openclaw/openclaw
- **Stars:** 211,406
- **Language:** TypeScript
- **Size:** 208 MB
- **Description:** Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞
- **Key Features:**
  - Multi-agent routing with isolated workspaces
  - Local-first gateway architecture
  - Tool system with 5,700+ community skills via ClawHub
  - Command: `npm install -g openclaw@latest` then `openclaw onboard --install-daemon`

### PicoClaw
- **GitHub:** https://github.com/sipeed/picoclaw
- **Stars:** 16,338
- **Language:** Go
- **Size:** 17 MB
- **Description:** Tiny, Fast, and Deployable anywhere — automate the mundane, unleash your creativity
- **Key Features:**
  - Runs on $10 hardware (Raspberry Pi Zero, old phones)
  - <10MB RAM footprint
  - 95% AI-generated code with human refinement
  - Fast boot times (~1 second)
  - Command: Download binary from releases and run, or build from source

### ZeroClaw
- **GitHub:** https://github.com/zeroclaw-labs/zeroclaw
- **Stars:** 14,920
- **Language:** Rust
- **Size:** 7.4 MB
- **Description:** Fast, small, and fully autonomous AI assistant infrastructure — deploy anywhere, swap anything 🦀
- **Key Features:**
  - 400x faster startup than alternatives
  - Memory-safe, sandboxed execution
  - Zero-trust architecture with explicit permissions
  - Runs on $10 hardware with <5MB RAM
  - Command: `git clone && ./bootstrap.sh` or `cargo install zeroclaw`

### nanobot
- **GitHub:** https://github.com/nanobot-ai/nanobot
- **Stars:** 1,014
- **Language:** Go
- **Size:** 3 MB
- **Description:** Build MCP Agents - MCP host for AI agents
- **Key Features:**
  - Standalone MCP host for building AI agents
  - Integrates MCP servers with LLMs
  - Web UI at http://localhost:8080
  - Supports OpenAI and Anthropic models
  - Command: `brew install nanobot-ai/tap/nanobot` then `nanobot run ./nanobot.yaml`

### ClawHub
- **GitHub:** https://github.com/openclaw/clawhub
- **Stars:** 2,353
- **Language:** TypeScript
- **Size:** 1.9 MB
- **Description:** Skill Directory for OpenClaw
- **Key Features:**
  - 5,700+ community-built skills
  - Vector search for skill discovery
  - CLI for easy installation
  - Community moderation and automated scanning
  - Commands: `clawhub search "query"`, `clawhub install skill-name`, `clawhub list`

## Security Incidents

### Moltbook Database Exposure (January 2026)
- **What happened:** A public Moltbook instance exposed user data due to misconfigured database settings
- **Impact:** User messages and potentially sensitive data were publicly accessible
- **Mitigation:** Use `openclaw doctor` to audit configuration before deployment
- **Source:** 404 Media, Cisco Blogs

### "What Would Elon Do?" Malicious Skill
- **What happened:** A skill in ClawHub silently collected user data
- **Impact:** Privacy violation for affected users
- **Mitigation:** Review skill code before installing, especially from untrusted authors
- **Source:** Cisco Blogs

## Claw Family Philosophy

The Claw family shares a common philosophy: **personal AI that you own and control.** 

Key principles:
1. **Local-first** - Run on your own hardware when possible
2. **Open source** - MIT licensed, community-driven
3. **Extensible** - Plugin/skill system for customization
4. **Privacy-focused** - You control your data
5. **Lobster-themed** - The family mascot is a space lobster named Molty
