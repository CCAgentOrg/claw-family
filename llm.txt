# AI Agent Frameworks Microsite

This file provides context for AI assistants understanding this project.

## Overview

This is a comparison and guide website for AI agent frameworks. It helps developers and users choose the right framework for building personal AI assistants.

## Featured Frameworks

### 1. OpenAI Swarm
- **Repo**: openai/swarm
- **Language**: Python
- **Stars**: ~21,000
- **Size**: 499 KB
- **Description**: Lightweight multi-agent orchestration framework by OpenAI
- **Best For**: Simple multi-agent coordination with minimal overhead
- **Key Features**: Handoffs, function calling, state management

### 2. nanobot
- **Repo**: nanobot-ai/nanobot
- **Language**: Python
- **Stars**: ~1,000
- **Size**: 33 KB
- **Description**: Personal AI assistant for chat platforms (WhatsApp, Telegram, Discord)
- **Best For**: Personal assistants, chat bots, lightweight deployments
- **Key Features**: Multi-channel support, skills system, memory management

### 3. GPTScript
- **Repo**: gptscript-ai/gptscript
- **Language**: Go
- **Stars**: ~3,300
- **Size**: 5.2 MB
- **Description**: Go-based AI scripting framework with natural language tool definitions
- **Best For**: Enterprise scripting, Go developers, production deployments
- **Key Features**: Natural language tool definitions, fast execution, enterprise-ready

### 4. AutoGen
- **Repo**: microsoft/autogen
- **Language**: Python
- **Stars**: ~55,000
- **Size**: 148 MB
- **Description**: Multi-agent conversation framework by Microsoft
- **Best For**: Complex multi-agent workflows, research applications
- **Key Features**: Conversational agents, code execution, human-in-the-loop

### 5. LangGraph
- **Repo**: langchain-ai/langgraph
- **Language**: Python
- **Stars**: ~25,000
- **Size**: 508 MB
- **Description**: Stateful multi-actor applications with graph-based orchestration
- **Best For**: Graph-based workflows, LangChain ecosystem users
- **Key Features**: State management, graph visualization, persistence

### 6. Open Interpreter
- **Repo**: openinterpreter/open-interpreter
- **Language**: Python
- **Stars**: ~62,000
- **Size**: 100 MB
- **Description**: Code execution agent that runs code locally
- **Best For**: Code execution, data analysis, development tasks
- **Key Features**: Multi-language support, local execution, interactive mode

## Technical Implementation

### Auto-Update System
- Fetches live stats from GitHub API
- Caches in localStorage for 1 hour
- Falls back to stats.json for offline mode
- Shows "(live)", "(cached)", or "(offline)" indicator

### Frontend Stack
- **HTML5**: Semantic markup
- **CSS3**: Custom dark theme, responsive design
- **JavaScript**: Vanilla JS, no frameworks

### Deployment Options
- Cloudflare Pages (recommended)
- Vercel
- Netlify
- GitHub Pages

## Security Notes

AI agents execute code and access data. Users should:
- Review tool permissions before granting access
- Sandbox code execution environments
- Use environment variables for API keys
- Implement rate limiting and access controls
- Audit agent logs regularly

## Quick Start Commands

```bash
# Install dependencies
npm install

# Local development
npm start

# Check infographics
npm run check:infographics

# Build and check
npm run build

# Test GitHub API
npm run test

# Deploy to Cloudflare Pages
npm run deploy:cloudflare

# Deploy to Vercel
npm run deploy:vercel

# Deploy to Netlify
npm run deploy:netlify
```

## Usage Guidelines

When helping users with this site:
1. Refer to specific framework IDs (swarm, nanobot, gptscript, autogen, langgraph, interpreter)
2. Check stats.json for current fallback values
3. Use deployment commands from DEPLOYMENT.md
4. Verify infographics exist before deployment
