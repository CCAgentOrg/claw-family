# LLM.txt - AI Context for Claw Family Microsite

## Project Overview

This is an auto-updating microsite that displays real-time statistics about the Claw family of AI agent frameworks: OpenClaw, nanobot, PicoClaw, and ZeroClaw.

**Repository:** claw-microsite
**Purpose:** Serve as a starter template for anyone wanting to explore personal AI agents
**License:** MIT

## Technical Architecture

### Frontend Stack
- **HTML5** - Single-page application structure
- **CSS3** - Custom responsive CSS with CSS variables for theming
- **Vanilla JavaScript** - No frameworks, pure JS for auto-updating functionality

### Key Components

1. **index.html** - Main page with:
   - Overview section with live stats grid
   - Individual framework sections (OpenClaw, nanobot, PicoClaw, ZeroClaw)
   - Comparison table
   - Quick start guide with scenario-based recommendations
   - Security advisory section
   - Infographics section (animated GIFs)

2. **styles.css** - Styling with:
   - Dark theme optimized for developer audiences
   - Responsive grid layouts
   - CSS custom properties for easy theming
   - Mobile-first design

3. **script.js** - Auto-update logic:
   - GitHub API integration for live stats
   - localStorage caching (1-hour duration)
   - Fallback to stats.json for offline mode
   - Status indicators (live/cached/offline)

4. **llm.txt** - This file (AI context)

5. **stats.json** - Fallback data generated by:
   ```bash
   node scripts/fresh-stats.js > stats.json
   ```

## API Endpoints

The site uses the GitHub REST API:

```
https://api.github.com/repos/{owner}/{repo}
```

### Monitored Repositories:
- `openclaw/openclaw` - TypeScript, full-featured
- `nanobot-ai/nanobot` - Python, minimalist
- `picoclaw/picoclaw` - Go, ultra-light
- `zeroclaw/zeroclaw` - Rust, security-first

### Data Retrieved:
- `stargazers_count` - GitHub stars
- `forks_count` - GitHub forks
- `updated_at` - Last update timestamp

## Caching Strategy

1. **localStorage Cache:**
   - Key: `claw-stats`
   - Duration: 1 hour (60 * 60 * 1000 ms)
   - Structure: `{ timestamp: number, data: object }`

2. **Fallback:**
   - `stats.json` - Static file with recent stats
   - Generated by `scripts/fresh-stats.js`

3. **Hardcoded Fallback:**
   - If both API and stats.json fail, use hardcoded values

## Security Considerations

### Known Incidents Documented:

1. **Moltbook Database Exposure (Jan 31, 2026)**
   - 2.3 million encrypted messages exposed
   - Source: 404 Media

2. **"What Would Elon Do?" Skill Incident**
   - Malicious skill in ClawHub attempting prompt injection
   - Source: Cisco Blogs

### Best Practices for Forks:
- Review all third-party skills before installation
- Run agents with minimal permissions
- Use ZeroClaw for security-critical deployments
- Keep dependencies updated
- Encrypt sensitive data at rest

## Customization Guide

### Adding New Frameworks

1. Add to `REPOSITORIES` object in `script.js`:
```javascript
const REPOSITORIES = {
    // ... existing
    newclaw: { owner: 'owner', repo: 'newclaw' }
};
```

2. Add stat card HTML in `index.html`:
```html
<div class="stat-card" data-framework="newclaw">
    <h3>NewClaw</h3>
    <div class="stat-value" data-type="stars">Loading...</div>
    <div class="stat-value" data-type="forks">Loading...</div>
    <span class="badge type">Type</span>
</div>
```

3. Add framework section:
```html
<section id="newclaw">
    <h2>🦀 NewClaw</h2>
    <div class="framework-info">
        <!-- Content -->
    </div>
</section>
```

4. Update comparison table in `index.html`

### Changing Colors

Edit CSS variables in `styles.css`:
```css
:root {
    --primary: #e84228;
    --accent: #667eea;
    /* ... */
}
```

### Modifying Cache Duration

Edit `CACHE_DURATION` in `script.js`:
```javascript
const CACHE_DURATION = 60 * 60 * 1000; // 1 hour
```
